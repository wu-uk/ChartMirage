# Data Charts Generation Module

该模块用于生成或处理图表数据及其相关的描述信息。

## 目录内容

- `*.png`: 包含示例图表，如 `01_sales_trend_poisoned.png` (受攻击示例) 和 `02_market_share_clean.png` (正常示例)。
- [caption.txt](file:///home/ASC26team2/wuyukai/project/ChartMirage/data_charts_gen/caption.txt): 存储图表的描述或标注信息。

## 用途

主要用于生成对抗性样本的原始素材，或作为演示图表理解能力的测试数据。
